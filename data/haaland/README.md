# Haaland shot data

`erling_haaland_2022_understat.csv` was copied unchanged from [football-plot](https://github.com/prithvi-kaizen/football-plot/blob/main/erling_haaland_2022_understat.csv) on 21 October 2026 before archiving that small repository.

Original Git blob: `c4ea244e857e37668e9237575d51fce0d632dfd2`.

The file identifies Understat in its name and contains Erling Haaland shot records for the 2022 season (including match dates in 2023). It is a historical snapshot, not a live feed. This consolidation does not establish that the season is complete or validate every record. Preserve attribution to [Understat](https://understat.com/) and check its usage terms before redistributing data elsewhere.

Fields include normalized shot coordinates (`X`, `Y`), `xG`, outcome, match and player identifiers, and assist/action details. No coordinate conversion or cleaning was applied during this move.
